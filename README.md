# Jawosh Pharma Website

A modern pharmaceutical company website built with **Next.js**, **TailwindCSS**, **Framer Motion**, and **shadcn/ui**.

## 🚀 Tech Stack
- Next.js 15+
- React 19
- TailwindCSS
- shadcn/ui components
- Framer Motion for animations

npm install
npm run dev
